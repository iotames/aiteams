# Task: 需求分析与 PRD 编写

## Description

你需要为中小商户设计一个**进销存管理系统 (Inventory Management System, IMS)**，分析以下业务需求并编写完整的 PRD 文档。

### 核心业务功能

1. **商品管理** — 添加/编辑/删除商品、分类管理、库存数量跟踪
2. **采购管理** — 创建采购单、入库操作、采购记录查询
3. **销售管理** — 创建销售单、出库操作、销售记录查询
4. **库存管理** — 库存盘点、低库存预警、库存流水
5. **报表统计** — 销售统计、采购统计、库存汇总

### 输出要求

请输出一份完整的 PRD 文档，写入文件 `output/PRD.md`，包含以下章节：

1. **项目背景与目标**
   - 中小商户面临的管理痛点
   - 系统建设的核心目标
   - 成功标准

2. **目标用户画像**
   - 管理员（老板）的需求
   - 操作员（店员）的需求

3. **功能模块详细描述**
   - 每个模块的界面列表
   - 每个功能的操作步骤
   - 数据字段定义（字段名、类型、必填、默认值）
   - 交互流程（含异常流程）

4. **用户角色与权限**
   - 角色定义
   - 各角色可访问的模块和操作

5. **非功能性需求**
   - 响应时间要求
   - 数据安全要求
   - 并发用户数
   - 浏览器兼容性

6. **MVP 版本范围界定**
   - 第一期包含的功能
   - 后续可迭代的功能

## Expected Output

一份完整的 PRD Markdown 文档，保存在 `output/PRD.md` 中。
内容需要足够详细，能让架构师据此设计完整的系统架构，无需额外沟通。
