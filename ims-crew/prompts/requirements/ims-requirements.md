# 进销存管理系统 (IMS) — 产品需求规格

> 面向中小商户的轻量级进销存管理系统

---

## 1. 项目背景

中小商户在日常运营中普遍面临以下痛点：

- **库存管理混乱**：商品种类多、进出频繁，手工记录易出错
- **采购/销售数据分散**：纸质单据或 Excel 管理，难以汇总分析
- **缺乏预警机制**：库存积压或断货无法及时发现
- **报表缺失**：无法快速了解经营状况（毛利、畅销品、库存周转）

本系统旨在提供一个轻量、易用、零部署成本的进销存管理方案。

## 2. 目标用户

| 用户角色 | 使用场景 | 核心需求 |
|---------|---------|---------|
| 商户老板/管理员 | 查看经营数据、管理商品、分析报表 | 完整的采购/销售/库存/报表管理权限 |
| 店员/操作员 | 日常开单、入库、出库操作 | 快速开单、库存查询、基础操作 |

## 3. 功能范围

### 第一期 (MVP)

| 模块 | 功能 | 优先级 |
|------|------|--------|
| 商品管理 | 商品 CRUD、分类管理、库存查看 | P0 |
| 采购管理 | 创建采购单、入库操作、采购记录查询 | P0 |
| 销售管理 | 创建销售单、出库操作、销售记录查询 | P0 |
| 库存管理 | 库存流水查看、低库存预警 | P1 |
| 报表统计 | 销售统计（按日/月）、采购统计、库存汇总 | P1 |

### 后续迭代

- 用户登录与权限管理
- 多商户支持
- 供应商/客户管理
- 打印单据
- 数据导出 (Excel/PDF)
- 商品图片上传
- 条码扫描

## 4. 技术约束

- 后端: Python FastAPI + SQLAlchemy 2.0
- 前端: 纯 HTML/CSS/JS + Bootstrap 5（零构建工具）
- 数据库: SQLite（开发）/ PostgreSQL（生产）
- 部署: Docker Compose

## 5. 数据概要

| 表 | 说明 |
|----|------|
| categories | 商品分类 |
| products | 商品基本信息 + 库存数量 |
| purchases + purchase_items | 采购单 + 采购明细 |
| sales + sale_items | 销售单 + 销售明细 |
| inventory_logs | 库存变动流水 |
