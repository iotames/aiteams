## 端口监听进程的清理纪律

启动了**监听端口**的进程（`node server`、vite、dev server 等），**任务完成后默认主动关闭，或明确询问是否关闭**，不得放任其残留占用端口。

- Why：残留进程会持续占用端口，导致用户重启同一服务时报「端口被占用」；也可能在会话结束后继续占内存。历史教训：后台起 `dsh web` 占住 3080，用户再执行时报错。

要点：
1. 后台临时起的服务，验证完立即停掉，并把端口腾回给用户。
2. 若服务还需继续运行，明确告知进程 PID、日志位置，并询问「是否关闭」再离开。
3. 不确定用户是否还需要时，一律先询问，不默认保留。
