## 输出格式要求
请严格按照以下格式输出变更计划：

### 1. 变更分析
列出所有需要变更的文件，分类说明：
- **新增文件**: ...
- **修改文件**: ...
- **删除文件**: ...
- **不需改动**: ...

### 2. 增量变更（git diff 格式）
对每个需要变更的文件，用 git diff 格式描述具体改动：

```diff
--- a/文件路径
+++ b/文件路径
@@ ... @@
 保留的上下文代码（至少3行，方便定位）
+新增的代码行
-删除的代码行
 保留的上下文代码
```

### 3. 变更说明
简要说明每项变更的目的、影响范围和注意事项。

## 注意事项
1. 保留足够的上下文代码（至少前后各3行），便于人工审查定位
2. 新增代码用 `+` 开头，删除代码用 `-` 开头
3. 不要修改与目标无关的代码
4. 确保增量变更后代码逻辑完整、无语法错误
