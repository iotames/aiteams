# aiteams — AI Agents 团队工场

> 面向生产环境的工程化多 Agent 团队集合。每个子目录都是一个独立的 AI 团队，服务于具体的业务场景。

## 团队目录

| 团队 | 技术栈 | 场景 |
|------|--------|------|
| [ims-crew](./ims-crew/) | CrewAI | 进销存管理系统自动生成 |

## 设计原则

- **工程化优先** — 每个团队都具备完整的 CLI、配置、CI 就绪结构
- **解耦提示词** — Agent 角色和任务描述尽量以 `.md` 文件管理，与代码分离
- **可复用** — 团队配置和提示词可在项目间移植
- **技术栈无关** — 不绑定单一框架，按场景选用最合适的 Agent 编排方案

## 项目结构

```
aiteams/
├── README.md              # 本文件
├── .gitignore             # 全局忽略规则
├── team-alpha/            # 下一个 AI 团队（示例）
└── ims-crew/              # 进销存系统开发团队
    ├── prompts/           # 提示词文件
    ├── src/               # 源代码
    └── README.md          # 团队使用说明
```

## 快速开始

每个团队独立运行，进入对应目录查看各自的 README：

```bash
cd ims-crew
cat README.md
```
